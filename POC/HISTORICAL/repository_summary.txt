# OpenOrgel Repository Summary

## README.md
This file contains the project's foundational documentation and vision. It outlines OpenOrgel as a 2026 open-source, portable pipe organ project constructed from wood and 3D-printed PLA. It details the mechanical design, including a custom electric centrifugal blower, a closed-loop wind system with sensors and dynamic RPM control, and the rationale behind combining physical pipes with digital synthesis for extreme ranges (C0-C8). It also explains the project's educational and cultural mission to make the complex and expensive pipe organ accessible for musical education worldwide.

## newsynthesis.py
This is the core Python application for the digital synthesis component of the organ. It features a CustomTkinter (CTk) dark-mode graphical user interface (GUI) and interfaces with the high-performance C++ engine (openorgelsynth.dll via ctypes) with automatic Python fallback to generate highly realistic organ tones (including inharmonicity, wind chiff, pitch drift, and cabinet resonance). It handles MIDI file loading, playback, and WAV export, caches generated tones for performance, and runs a background thread listening to a connected Arduino/Teensy over Serial to map physical console switches to digital organ stops.

## openorgelsynth.cpp
This is the high-performance C++ synthesis engine compiled into `openorgelsynth.dll` using LLVM-MinGW. It performs multi-threaded SIMD additive synthesis, real-time Schroeder multi-tap reverb, and MP3 sample resampling using `dr_mp3.h` for sample-based stops (`stoppedflue.mp3` for Acoustic Flue footages & mixtures, and `clarion.mp3` for Clarinet footages).

## organconsole.ino
This is the C++ firmware for the Arduino/Teensy microcontroller acting as the physical switchboard for the organ. It reads toggle switch states using pull-up resistors and sends formatted serial commands (e.g. `Oboe 8':1`) to the synthesis application. It also controls the wind blower motor driver when the master switch is engaged.

## newsynthesis.spec
This is a PyInstaller specification file used to bundle `newsynthesis.py`, `openorgelsynth.dll`, and all dependencies into a standalone Windows executable (`openorgelsynth.exe`).

## project_timeline.txt
A detailed chronological history and milestone record documenting every phase of the OpenOrgel project, from initial proof-of-concept synthesis to C++ DLL porting and sample-based stop architecture.

## update_history.py & commits_and_releases.txt
Automated Git history tracking tool that formats commit logs, annotated version release tags, and author history into `commits_and_releases.txt` for release packaging.
